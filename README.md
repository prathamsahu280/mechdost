# MechDost

Automotive products and local vehicle care — Raipur first, multi-city by design.

Customer storefront, admin-routed product orders with shop acceptance, location-first workshop service requests with per-line estimate approval, partner portals for shops and workshops, and an analytics-first admin console.

- **Decisions & pending items:** [`docs/decisions.md`](docs/decisions.md)
- **Feature specs:** [`docs/specs/`](docs/specs/README.md)
- **Plan:** [`docs/plan.md`](docs/plan.md)

Stack: Turborepo + pnpm · Next.js (App Router) · Hono API · Drizzle + Supabase Postgres (PostGIS) · Firebase Auth (phone OTP) · Upstash Redis · pg-boss · Razorpay · MapLibre.
