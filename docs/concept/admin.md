## 4. Data model (inferred)

Product `{id, version, name≤160, sku≤80 unique ci, category(9), brand≤100, spec≤2000, compatibility≤1000, photo, published, import_data{mrp, sellingPrice, stock, hsn, gstRate}}`. Vendor `{id, version, name, contact, phone, gstin?, address, city, pins[], approved}`. Offer `{id, version, product_id, vendor_id, pin, purchase_paise, selling_paise, shipping_paise, stock, lead_days, valid_until, active}` (public only if product published, vendor approved, active, not expired, stock>0). Audit `{at, action, record_id}`. Order `{id, status, created_at, name, phone, address, city, state, pin, items[], total_paise}`. User `{id, name, email, phone, role}`. Access link `{workshop_id, user_id, enabled, note}`. Booking `{id, workshop_id, status, payment_state, total_paise, appointment_at}`. Payment `{id, kind, booking_id, amount_paise, status, provider_order, provider_payment}`. Enquiry `{id REQ-uuid, kind, status, created_at, name, business, phone, pin?, details, consent_at}` (admin statuses In review / Awaiting customer / Resolved / Closed). Workshop (see editor). Backup `{id, kind daily|manual, status, created_at, completed_at, row_count, table_count, media_count, bytes, error}`.

## 6. Bugs / gaps (do not reproduce)

Nav highlight stale (readiness/batch/orders never set active; orders title not reset); titles ≠ nav labels; readiness "service entries" jumps to Members which lacks a service-menu UI; `notify()` styles errors as success and never clears; JSON parsed before status check (HTML errors crash); order status parsed from rendered text; transitions hard-coded client-side; enquiry select ignores current status, reply required to change status, past replies hidden, no approve/convert; batch offers limited to 100, purchase never prefilled, log shows product id, stale local db; batch photo posts whole product object; import hint contradicts update mode; CRUD search matches hidden fields; vendor PINs unvalidated (`JSON.parse` crash risk); offer PIN not checked vs vendor; margin ignores GST/shipping; audit unlimited/raw; workshop "confirmed" never pre-ticked, owner name/phone change resets verification, no city/service-area fields; members: unstyled error, read-only bookings, `booking_id` holds order ids, reconcile shown when gateway absent; backup fallback filename reused for CSV; contradictory payment copy; missing import `.mjs` files; double-encoded capture.
