## 4. Public API shapes

- `GET /api/catalog` → `{"scope":"India","items":[{id, name, category, brand, sku, spec, compatibility, photo, fromPrice}]}` (fromPrice in rupees). `?pin=` adds `stock`, `sellingPrice`, `shipping`, `leadDays`.
- `GET /api/workshops` → `{"workshops":[]}`. `GET /api/workshops/{id}/services` → `{bookingEnabled, workshop:{name,address,pin}, services:[{id,title,description,inclusions,exclusions,low_paise,high_paise,duration}]}`.
