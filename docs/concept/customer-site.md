## 0. How the code is put together

- `index.html` loads only `/mechdost-runtime.js` (plus a Cloudflare challenge snippet, not part of the app).
- The runtime bundles **20 modules** run in order: app.js, prototype.js, mechanics.js, service-workshop.js, vehicle-services.js, connected-features.js, shopping.js, assistance-scan.js, service-packages.js, customer-improvements.js, vehicle-discovery.js, premium.js, simple.js, whatsapp.js, live-catalogue.js, customer-cart.js, service-hub.js, launch.js, member-entry.js, launch-refinements.js.
- Later modules **redefine** earlier functions (`bookService` 8×, `account` 7×). The visitor sees the **last** definition; older layers are mostly dead code but still loaded.

## 1. Routing and views (final behaviour)

- Route guard (`launchRouteGuard`): only `#home`, `#catalogue`, `#service-packages`, `#partners` allowed; anything else → `home`. Aliases: `#find-parts`→catalogue, `#garages`/`#services`→service-packages, `#my-vehicles`→`/account#vehicles`.
- `premiumRoute` groups: home = home, home-products, home-service · shop = catalogue, find-parts · services = service-packages (+garages, hidden by hub) · garage = my-vehicles · requests = service-desk · partners · learn = academy · mechanics · assistance. Sections without id (FAQ `.automart-faq`, `.closing`, `.premium-trust`) are hidden in every view.
- Visible: `#home` (hero, home-products, home-service); `#catalogue` (live catalogue + find-parts); `#service-packages` (service hub only — CSS hides the package grid/category grid/selectors); `#partners`.
- Present but unreachable: vehicle-quickbar, home-highlights, local-preview, vehicle-discovery-entry, discover-vehicles, my-vehicles, assistance, garages, service-desk, mechanics, academy, journey, FAQ, closing, trust. (All captured as `03-section-*.png`.)
- Other pages linked: `/account`, `/account#vehicles|#orders|#bookings`, `/account?workshop={id}#book`, `/admin`, `/support.html`, `/products/{id}`, `/workshops/{id}`.
