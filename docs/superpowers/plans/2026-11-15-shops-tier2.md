# Shop portal tier 2 — implementation plan (stock CSV, packing slip, performance, status lookup)

Date: 2026-11-15 · Design: `docs/superpowers/specs/2026-11-15-shops-next-tier-design.md` items 4 to 7 · Specs 07, 12, 13

Rules in force: all-or-nothing apply, prices only as price requests, owner-only performance with anonymous median, masked
phone on the slip, no schema change, no new dependency, en + hi under `shopTier2`, nothing in the header's modules.

## Tasks (test first, in order)

1. **Pure rules in `packages/shared`** — `shop-csv.ts` (parse on the existing RFC 4180 parser, formula cells, plan against the
   shop's catalogue, template), `shop-performance.ts` (metrics, median, benchmark with `SHOP_BENCHMARK_MIN`), `qr.ts` (own
   encoder, read-back test), `shop-tools.ts` (wire DTOs). Tests: `shop-csv`, `shop-performance`, `qr`.
2. **Repositories in `packages/db`** — `shop-csv.ts` (preview, apply in one transaction through `saveShopOffer` and
   `submitPriceRequest`, audit row, events), `shop-slip.ts`, `shop-performance.ts` (three indexed scans merged),
   `partner-status.ts`. Test `shop-tools.test.ts` (atomicity, price request not price, slip leaks, edge of the benchmark,
   status phone match).
3. **API `routes/shop-tools.ts`** — multipart CSV with its own body limit (security middleware skips the path), hourly limit,
   slip, owner-only performance, public status with Firebase token (no user row), per-IP and per-phone limits. Test
   `apps/api/test/shop-tools.test.ts` (role-leak matrix, limits, 404 equality).
4. **Web** — `shop-csv-api`, `shop-performance-api`, `shop-slip-api` + page, `partner-status` + page, view helpers and a
   unit test (keys in en and hi, Hindi without English words); locale namespace; `ClientMessages` lists.
5. **Audit rows** — `API-SHOP-TIER2`, `API-SHOP-SLIP`, `API-PARTNER-STATUS` with typed fixtures and hooks; regenerate the
   checklist.
6. **Docs and ledger** — spec 07 built section, spec 12 events, decisions, progress, questions Q118 to Q120, both learnings
   files.

Gate (targeted only, by instruction): the new tests, typecheck and eslint/prettier on touched packages.
