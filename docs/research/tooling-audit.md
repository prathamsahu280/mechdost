## F. Project-local skills (to write with `skill-creator` / `writing-skills`)

Skill = `.claude/skills/<name>/SKILL.md` (project scope, committed). Frontmatter: `name`, `description` (+`when_to_use`, ≤1,536 chars combined), `argument-hint`, `allowed-tools`, `disallowed-tools`, `model`, `effort`, `context: fork`, `hooks`, `paths` (glob auto-activation), `shell: powershell`. Body <500 lines; `scripts/` executed, `references/` loaded on demand, `assets/`, `evals/evals.json`.

- **`mechdost-advisor`** — "Checks a proposed change against MechDost decisions, specs and design system; researches current best practice (Context7/web); flags conflicts and suggests improvements." `allowed-tools: Read Grep Glob WebSearch WebFetch`, `paths: ["docs/**","packages/**","apps/**"]`. Steps: read `docs/decisions.md`, `docs/specs/*`, `CLAUDE.md`; list conflicts; research; output decision/risk table; propose doc updates.
- **`website-testing`** — "Run and triage MechDost tests: Vitest unit, Playwright E2E (incl. concurrency and role-leak suites), Lighthouse CI, axe." `allowed-tools: Bash(pnpm test:*) Bash(pnpm exec playwright:*) Bash(npx lhci:*) Read Grep`, `context: fork`; `scripts/run-all.ps1`; `references/thresholds.md` (budgets).
- Also local: `firebase-phone-auth-rbac`, `razorpay-payments`, `drizzle-postgis-supabase`, `msg91-messaging`, `serwist-pwa`, `next-intl-hindi`.
