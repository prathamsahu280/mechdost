## 2. Second shop and reroute (pass)

How shop B got the product: the shop owner portal's "Sell another product" is a single block that always targets the owner's **first** shop (the input ids carry that shop's id; no shop picker). So the product that only the second shop lacked had to be chosen the other way round: wheel bearing BRG-6301-2RS was stocked at Sharma Auto Parts (A), and Raipur Battery Point (B) requested it through "Sell another product" (price ₹180, stock 10, "Send for approval"); admin approved it in Partners, Price requests. Both shops belong to the shop owner account.

COD order of 6 bearings (₹1,080 + ₹40): admin routed to A (offer visible on the shop page within a few seconds). A declined with "out of stock"; admin queue showed "Declined by Sharma Auto Parts: out of stock" after 6 s with no reload; the suggestion list then offered only B. Admin rerouted to B (B saw it in 7.6 s). B accepted, packed, marked out for delivery, delivered with the customer's code. Customer page followed without a reload: confirmed about 16 to 45 s after accept, out for delivery about 12 s, delivered about 50 s (poll interval 30 s; no live channel in this build). Wrong delivery code was not retried this pass (done in pass 3).
