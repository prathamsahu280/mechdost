## Sign-in findings (read first)

- **Staff sign-in works; the early failures were harness-caused.** Customer, shop and workshop sign in with phone and password at once. The admin (staff) second step sends a Firebase SMS code through reCAPTCHA. The on-screen text was "Sign-in isn't working right now" (when the page lost the reCAPTCHA verifier because the script's browser closed between runs) and "We couldn't finish the security check. Press the button again" (reCAPTCHA challenge not solved). The network was healthy each time: `POST /v1/auth/password` 200 with `{status: staff_code}`, identitytoolkit `recaptchaConfig` 200, `recaptchaParams` 200, `accounts:sendVerificationCode` 200 with a session. With a window that stays open, the code step appears and `123456` signs in to `/admin`.
- **The reCAPTCHA challenge is visible and it appears every time in an automated browser.** An image challenge ("Select all squares with buses, if there are none click Skip") shows over the form on every staff sign-in attempt from this harness; it needs a human. Customer, shop and workshop sign-ins never showed one. Whether a normal browser shows it every time was not measured. Real staff will see it whenever Google scores the browser as unusual. The two failure messages above are both shown for the same unsolved challenge, which is confusing; the first one (the "isn't working" wording) is wrong for "challenge not finished".
- **Bug: signed in with an account that has no name, `/login` says "You're signed in as ."** (empty name).

## Bugs

1. **Medium.** Signed out, `/orders/<code>-1` and `/quotes/<code>` say "We could not find ..." with no sign-in link (parent codes and `/service/<code>` ask to sign in correctly). Known, being fixed elsewhere.
2. **Low to medium.** The per-shop order code `/orders/<code>-1` is "not found" for everyone including the owner, and the page makes no API call. Customer mails use the parent code, so mails are not affected; shop codes shown elsewhere (shop mails, admin) are not links to this page. If any message links a per-shop code it dead-ends.
3. **Medium.** `/account/support?ticket=<code>` signed out: the login link drops the ticket (`next=/account/support`). Known, being fixed elsewhere.
4. **Medium.** Customer service page says "Paid at the workshop on 16 Nov 2026." after paying online by card (payment row `card`, `service_bill`). Wrong sentence for an online payment.
5. **Medium.** The workshop's job card keeps showing "Estimate v1 · ₹1,650 with GST" with the declined line included and no approved or declined mark per line, although the customer declined one line (bill is correct at ₹1,250). The text also says "with GST" for a workshop that is not GST registered.
6. **Low.** Workshop "Vehicle received" is enabled before any before photo exists (the page says a photo is needed); the label "Needed" also stays after a photo was added ("1 of 6 added").
7. **Low.** Checkout summary says "Free delivery on orders from ₹999." but charges ₹40 on a ₹1,000 order and ₹80 on a ₹1,270 order (and ₹40 on ₹2,890). Either the rule is per shop, or the text or the rule is wrong.
8. **Low.** Admin routing screen says "No shop can take it now: every shop is paused or suspended" when the real reason is that no other shop stocks the item.
9. **Low.** A COD order cannot be cancelled by the customer because the admin settings are off; the order page gives no hint ("ask support" only). Spec 05 says customers cancel until packed. Check the intended default.
10. **Medium.** The customer support thread page did not show the admin's reply within 60 s without a reload (orders, service, quote chat and shop offers all updated live).
11. **Low.** `/login` while signed in with no profile name: "You're signed in as ." Also, the customer account has no name, so greetings read "Hello" and admin shows "Customer: Customer".
12. **Low.** One click on "Out for delivery" sent two `POST /v1/shop/orders/<code>/advance` requests (both 200).
13. **Low.** Bulk quote product search shows nothing while typing; results appear only after Enter or the search button.
14. **Low.** Customer rejected-order page shows "Total: ₹0" next to a refund of ₹1,040.
15. **Info.** Shop stock upload hint is English column names on `/hi` (see C).
