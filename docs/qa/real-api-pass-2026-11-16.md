## Bugs

1. **Sign-up retry sticks on "Sign-in isn't working right now"** (fixed in f08d43a). Steps: sign up; the step after linking the password fails (Turnstile or network); press Create account again. Cause: linking turns the Firebase session into a `password` provider session, and the retry first calls `GET /v1/me`, which the API refuses (`401 PROVIDER_NOT_ALLOWED`, `apps/api/src/auth/firebase-verifier.ts`). Re-tested after the fix: pass.
2. **CSP blocked reCAPTCHA's connect call** (`https://www.google.com/recaptcha/api2/clr`) on the phone-code step (console errors; sending still worked). Fixed in f08d43a (connect-src allows `https://www.google.com/recaptcha/`).
3. **Account page shows demo placeholder data in real mode.** After sign-in with the account whose profile name is empty (the half-finished first sign-up), `/account` says "Hello, Rakesh Sharma" and "Member since 1 Aug 2026" for a real signed-in user. Expected: the user's own name (or a neutral greeting) and the real creation date. Screenshot: scratchpad `bug-account-demo-name.png` (session scratchpad, not kept in the repo).
4. **Admin console shows the demo footer in real mode.** `/admin` ends with "Demo: actions are stored on this device. Open the customer pages in another tab to see updates live." while connected to the API.
5. **A half-finished sign-up leaves a user with no name** (profile saved only at the end of sign-up). With bug 1 fixed the retry saves it; a user who abandons stays nameless, which feeds bug 3.
6. **Production database has no content and no notification templates**: the catalogue, shops, workshops and `notification_templates` need to be created (admin console or seeds, user's call) before an order pass can run.
7. Minor: Turnstile logs "Cannot find Widget ... consider using turnstile.remove()" warnings on every sign-in form (console only).
