- T10 · 2026-11-01 · e2e · `waitUntil: 'networkidle'` hung on the map page and the "every button" audit clicked map pins that were outside the map's clipped area, plus a full-screen control that covered the page. → Wait for `load` + a short settle on map pages; exclude map pins from generic click audits (dedicated map test covers them); exit full screen after each click; run click audits with reduced motion so animations/transitions settle instantly. · active
- T11 · 2026-11-01 · links · The link crawler caught a product-page link to a route that did not exist yet (`/quotes/new`). → Keep the crawler in every run; never link to a planned route before the page exists. · active
- T12 · 2026-11-01 · locators · Decorative `aria-hidden` emoji change `textContent` but not the accessible name. → Assert labels with `toHaveAccessibleName`, not `toHaveText`, on controls that carry icons/emoji. · active
- T13 · 2026-11-02 · flaky · An intermittent `_rsc` 404 could not be reproduced with curl, sequential, concurrent or delayed runs. The retained Playwright trace (`trace.zip` → `*.network`) showed the request headers and pinned it in minutes (`next-router-segment-prefetch: /$d$locale/__PAGE__` against prerendered URLs). → For intermittent network failures, read the failing test's trace network log first; when excluding framework noise, match the exact header + status, never a broad pattern. · active
- T14 · 2026-11-02 · contrast · User found typed text invisible in the dark-mode hero search (fixed `bg-white` box + theme `text-ink`). axe passed because it checks text nodes, not input values. → `e2e/typed-text.spec.ts` types into key fields and measures real contrast in both themes; never use fixed white/black backgrounds behind theme-coloured text (use surface tokens). · active
- T15 · 2026-11-01 · visual review · Full-page screenshots cannot show `position: sticky` (the workshop map looked "not sticky" but already was) and they paint fixed elements (tab bar, assistant button) mid-page. → Verify sticky/fixed behaviour with a viewport screenshot after scrolling, not a full-page capture. · active
- T16 · 2026-11-01 · process · `playwright test | tail` reported exit 0 while 13 tests had failed (the pipe returns tail's status). → Redirect the run to a log file and read `$?` (or `PIPESTATUS`), then grep the summary for "failed" before saying anything passed. · active
- T17 · 2026-11-01 · i18n · A client component reused on two pages (`CartView` on /cart and /checkout) gained a new namespace; only one page's `ClientMessages` was updated → MISSING_MESSAGE on /checkout, caught by the console audit. → When a client component starts using a namespace, grep every page that renders it (directly or via another component) and add the namespace to each. · active
- T18 · 2026-11-01 · locators · A new footer link reused the exact label of an in-page link ("Ask for a bulk price"), making `getByRole('link', { name })` ambiguous — and confusing for screen-reader link lists. → Site-wide chrome uses labels distinct from in-page calls to action. · active
- T19 · 2026-11-01 · locale · After a test visits `/hi`, the NEXT_LOCALE cookie redirects later unprefixed URLs to Hindi, so English locators time out. → Clear the cookie (`context.clearCookies({ name: 'NEXT_LOCALE' })`) when a test switches back to English, or visit Hindi last.
- T20 · 2026-11-01 · locators · `getByRole('alert')` also matches Next's `#__next-route-announcer__`. → Match form errors by text or scope to the form. And every axe check needs `reducedMotion: 'reduce'`, or the fade-in produces a false 4.45 contrast.
- T21 · 2026-11-01 · assertions · A role-guard test asserted a redirect, but `PortalGuard` keeps the URL and swaps the content for "Sign in to continue". → Assert what protects the data (guard heading visible, console content hidden), not the URL.
- T22 · 2026-11-02 · load · After the home page gained ~30 next/image photos, a default-parallel e2e run timed out ~160 tests: first requests make the local `next start` encode AVIF per width and saturate the CPU. → Locally run `pnpm e2e --workers=3` (all green); treat mass `Test timeout` across unrelated specs as load first, and confirm by re-running one spec with fewer workers before debugging.
- T23 · 2026-11-02 · performance · Lighthouse simulated throttling (1.70 s) and applied CDP throttling (2.7 s) gave very different LCP for comparable pages. → Never compare numbers across methods; for a before/after, build the base branch in a temporary `git worktree`, serve it on another port and alternate runs with one script.
- T24 · 2026-11-02 · layout · Three times in one session a single-column CSS grid (implicit `auto` track) grew to the min-content of a non-wrapping child (truncated names, a nowrap chip row) and overflowed phones sideways. → Single-column grids get `grid-cols-1` (= `minmax(0,1fr)`); screenshot 360px after any nowrap/truncate change; the responsive sweep catches page overflow but not overflow clipped inside `overflow-hidden` panels — check those visually.
- T25 · 2026-11-02 · i18n · The language switcher worked in a fresh browser but not after a reload on a Hindi page: next-intl only syncs NEXT_LOCALE on document requests, and the switcher was a client-side `<Link>`. Fresh-context tests never set the cookie, so they passed. → Locale tests must start from a direct load of the other locale (cookie set) and include a reload; language switch links are plain `<a>`.
- T26 · 2026-11-03 · layout · A horizontal scroller (`overflow-x:auto`, not positioned) did not clip absolutely positioned `.sr-only` labels inside its off-screen items: their containing block was an ancestor outside the scroller, so the page grew ~3000px wide. Even `overflow:hidden` on the list did not help. → Every horizontal scroller (rails, carousels, chip rows) gets `position: relative`; bisect page overflow by hiding sections and comparing `documentElement.scrollWidth`.
- T27 · 2026-11-03 · infra · Background e2e and dev servers were killed by Claude Code under memory pressure on this laptop. → Run e2e in the foreground split by project (`--project=desktop` / `--project=mobile`, `--workers=2`, ≤10 min each).
