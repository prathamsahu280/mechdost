# Commands, suite map and environments

## Gates (run from the repo root)

| Command                                                                                                                    | What it runs                                                                                         | When                                                     |
| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `pnpm check`                                                                                                               | Prettier check + typecheck + ESLint (0 warnings) + all package tests (Turborepo, one task at a time) | Before every commit                                      |
| `pnpm --filter @mechdost/<pkg> test`                                                                                       | One package's Vitest suites                                                                          | While working on it                                      |
| `pnpm --filter @mechdost/web build` then `pnpm --filter @mechdost/web exec playwright test e2e/<file>.spec.ts --workers=1` | One browser suite against the production build                                                       | Before UI commits (low-memory machine: one file per run) |
| `node apps/web/scripts/measure-js.mjs` (with `next start --port 3100` running)                                             | Client JS budget, 180 KB gzip per page                                                               | After page changes                                       |
| `pnpm db:migrate`                                                                                                          | Apply migrations to `DATABASE_URL` (Supabase dev)                                                    | After schema changes, then the Supabase advisors via MCP |
| `pnpm lhci`                                                                                                                | Lighthouse CI                                                                                        | **Planned** (needs a preview deploy)                     |

## Environments

- **PGlite** (in-process Postgres 17 + PostGIS/citext/pg_trgm/btree_gist) via `@mechdost/db/testing` → `createTestDb()`. Single connection: proves constraints/triggers/CAS, not true parallelism.
- **Supabase dev** (`ewrszfqhgbrriqqggjts`) — migrations + advisors; never run destructive test data there.
- **Firebase Auth Emulator** (`FIREBASE_AUTH_EMULATOR_HOST=127.0.0.1:9099`, OTP `123456`); fetch codes via
  `GET http://127.0.0.1:9099/emulator/v1/projects/<id>/verificationCodes`.
- **Turnstile test keys**: site `1x00000000000000000000AA`, secret `1x0000000000000000000000000000000AA` (always pass);
  `2x...` variants always fail — use both in tests.
- **Razorpay**: test mode keys only; webhook tests sign payloads locally with a test secret.

## CI (`.github/workflows/ci.yml`)

Job `check`: frozen install → Prettier → typecheck + lint + unit tests → production build → `pnpm audit --audit-level=high` (report-only). Job `e2e-demo`: web build → Chromium → shell + demo-flows + hindi-coverage → JS budget. Node comes from `.nvmrc`. Planned: Postgres service-container concurrency suite, Lighthouse CI, visual suite.
